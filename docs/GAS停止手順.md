# GAS 版から Java 版への切り替え・GAS の停止手順　担当：指輪

GAS 版（「社員管理表」に付いたスクリプト）は、Java 版が本番で動いて、1か月分の集計が同じ結果になったことを確かめてから止める。
**途中で GAS を止めると、毎月の集計ができなくなるので順番を守る。**

## 1. Java 版を本番で動かす
- [ ] サーバーの置き場所を決める（Cloud Run など）。PostgreSQL を用意する
- [ ] 環境変数を入れる：SPRING_PROFILES_ACTIVE=prod、DB_URL など、ADMIN_PASSWORD、GOOGLE_CREDENTIALS（README 参照）
- [ ] サービスアカウントに、ひな型・社員フォルダの親・既存の社員の勤怠シート・GAS版の社員管理表を共有する

## 2. 設定と社員の引き継ぎ
- [ ] 画面「設定」に、ひな型・社員フォルダの親・退職者フォルダ・フォームの回答シート・社労士のメールを入れる
- [ ] 画面「設定」の「GAS 版からの切り替え」に、GAS版の社員管理表のURLを入れて「社員を取り込む」
  - 勤怠シート・フォルダ・共有状態はそのまま引き継ぐ（新しくは作らない）。退職者は取り込まない
- [ ] 社員一覧で、人数・勤怠シートのリンクが GAS 版と同じか確かめる

## 3. 1か月だけ両方で集計して比べる
- [ ] 同じ月を、GAS 版（メニュー「月次集計を作る」）と Java 版（画面「月次集計」→「集計する」）の両方で集計する
- [ ] 出勤日数・総労働・残業・深夜・手当・交通費の数字が同じか比べる。違えば理由を調べる（計算ルールを直すなら aggregate）
- [ ] 社労士には Java 版の CSV を送ってみて、読めるか確かめる

## 4. GAS を止める（Java 版で問題がないと決めたら）
- [ ] 「社員表の管理表」の Apps Script →「トリガー」で、毎朝7時の `shareDueSheets` を削除する（Java 版も毎朝7時に共有するので、二重にしない）
- [ ] 「デプロイ → デプロイを管理」で、ウェブアプリのデプロイをすべて「アーカイブ」する（GAS版の社員管理画面が開けなくなる）
- [ ] 勤怠表_ひな型・各社員の勤怠シートに付いている「勤怠提出ライブラリ」は使っていないので、Apps Script のライブラリから外す（任意）
- [ ] 「勤怠提出ライブラリ」プロジェクトはゴミ箱へ（任意）
- [ ] 社員管理表のスプレッドシートは消さずに「旧_社員管理表」に名前を変えて残す（記録として）
- [ ] チームと山本さんに「今月から Java 版を使う」と連絡し、ブックマークを Java 版のURLに替えてもらう
