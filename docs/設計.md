# 設計メモ

## 全体の流れ（毎月）
1. 【月次集計】①「全員の勤怠シートに月のシートを作る」… 各社員の勤怠シートの「テンプレ」を複製して「2026年12月」を作る
2. 社員が自分の勤怠シートに入力する。交通費・経費は Google フォームから申請し、山本さんが回答シートの「承認」列を TRUE にする
3. 【月次集計】②「集計する」… 全員の勤怠シートを読み、入力チェック → 集計ルール → 手当・インセンティブ・交通費・経費を足して保存
   - 入力エラーやシートがない人は、画面に一覧で出る（その人は集計しない）
4. 【月次集計】③ CSV をダウンロード、または社労士へメール
5. 【月次集計】④「確定」… 確定した月は集計し直さない

## 勤怠シートの読み方（attendance/MonthSheetParser）
- 月のシートの B11:G41（B日付・C出勤・D退勤・E休憩・F勤務時間・G備考）を、表示どおりの文字で読む
- J10 が標準時間（なければ 8:00）、「休日」シートの A2 以降が祝日
- 退勤が出勤以前なら日またぎ（夜勤）

## 集計ルール（aggregate/AggregationRules）… 仮。社労士に確認して直す
- 平日：1日の勤務が標準時間を超えた分を「残業」
- 土曜：勤務した時間をすべて「土曜出勤」
- 日曜・祝日：勤務した時間をすべて「休日出勤」
- 22:00〜翌5:00 は「深夜」（日曜・祝日は「休日深夜」）。休憩は深夜から引かない
- 備考「有給」→1日（「半休」「半日」は0.5日）、「特別休暇」「夏季休暇」→特別休暇1日
- 欠勤は数えない

## 表（db/migration）
